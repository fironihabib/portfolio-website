# Fironi Habibzade - Portfolio Website

A modern, responsive portfolio website showcasing my work as a Full Stack Developer and Entrepreneur.

**[www.fironihabib.bio](https://www.fironihabib.bio)**

## Features

- **Responsive Design** - Optimized for desktop, tablet, and mobile with swipe-enabled card navigation
- **Multilingual Support** - English, Azerbaijani, Turkish, and Russian with persistent language preference
- **Modern Card Layout** - Project showcase with glassmorphism effects and hover animations
- **Contact Form** - EmailJS integration for direct messaging
- **Smooth Animations** - Page transitions, typewriter effect, scroll-triggered animations

## Tech Stack

- HTML5, CSS3, JavaScript (ES6+)
- Google Fonts (Inter, DM Sans, K2D)
- Font Awesome 6
- EmailJS
- Netlify
